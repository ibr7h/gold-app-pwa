## الهدف المعماري

1. `ibr7h/dhahabk-user`: تطبيق المستخدم؛ إصدار CI/CD وبيئة نشر مستقلتان؛ الاحتفاظ بموقع المستخدم الثابت.
2. `ibr7h/dhahabk-trader`: تطبيق التاجر؛ إصدار وتثبيت وإشعارات منفصلة.
3. `ibr7h/dhahabk-admin`: الإدارة؛ تجارب Face ID/PIN/Push منفصلة عن المستخدم.
4. `ibr7h/dhahabk-marketers`: واجهة المسوّقين **بعد إنشاء مصدرها الحقيقي**، مع مراعاة العضوية المستقلة عن أدوار الحساب العامة.
5. `ibr7h/gold-app`: يبقى مستودع Backend موحّدًا ومقيدًا بالصلاحيات؛ لا ننسخ أسرار أو ملفات إنتاج أو قاعدة بيانات إلى مستودعات الواجهات.

## متطلبات النقل قبل إنشاء أي إصدار إنتاجي

### 1. إعادة إنتاج التطبيق من المصدر
- مستخدم Expo الحالي **ليس مستقلًا ضمن `apps/user` فقط**: يعتمد `.github/workflows/deploy-pages.yml` و`build-full-web.yml` على الملف `gold-app 17 apr 15-19 adimin icon.zip` مع `apps/user/overrides` وسكربتات بناء. يجب فك هذا الاعتماد واستعادة `package.json` والقفل وملفات Expo في مستودع مستخدم قابل للبناء من المصدر.
- ممنوع اعتبار مخرجات `_render_preview/` وحدها مصدرًا لتطوير التطبيق.
- اختبارات البناء، محاذاة واجهة iPhone، تحديث PWA، البريد وOTP، Face ID/PIN، تحديث الجلسة الواحدة، والتنبيهات شرط قبول.

### 2. استقلال حقيقي لكل PWA
- `manifest.id`, `start_url`, `scope`, `Service Worker`, كاش التحديثات، مفاتيح الجلسة، Web Push، إعدادات CI/CD والاستضافة منفصلة.
- لا تُغيّر نسخة الإدارة رقم إصدار أو ملفات /full/، ولا تُلغِ تسجيل عامل خدمة للمستخدم.
- نشر تطبيق واحد لا يبني ولا يعيد رفع تطبيقًا آخر من مصدره.
- يحتاج الحفاظ على `app.dhahabk.com` إلى مقارنة الأصل والمسار الفعلي و`manifest.id` على الاستضافة؛ **لم يتم التحقق من Render الآن**.

### 3. قواعد الأمان والاستعادة
- لا حذف ولا أرشفة للمستودعات القديمة أثناء الانتقال.
- لا تغيير لنطاق مستخدم حالي، ولا تغيير قاعدة بيانات إنتاج أو CORS أو مفاتيح Push دون تحقق ونسخة استعادة.
- تُنشأ المستودعات الجديدة **Private** مبدئيًا؛ لا تُنسخ `.env` أو كلمات مرور أو مفاتيح أو نسخ قواعد بيانات.
- ينبغي تثبيت معرّف Commit والنسخة الناجحة ومراجعة الـdiff قبل اعتماد أي انتقال.
- يمكن الاستفادة من PR المسودة: https://github.com/ibr7h/gold-app-pwa/pull/113 (تصحيح ترقيم إصدار المستخدم وحده **لا يحقق فصل النشر الكامل**).
